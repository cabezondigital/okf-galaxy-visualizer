# 🌐 [[Open Knowledge Format (OKF v0.2)]]

Open Knowledge Format v0.2 defines a vendor-neutral schema for knowledge management, combining YAML frontmatter metadata with bidirectional wikilinks.

## Core Pillars
- Frontmatter schemas with typed properties.
- Dynamic clustering based on semantic categories and tags.
- Explored visually using [[Galaxy Visualizer]].
