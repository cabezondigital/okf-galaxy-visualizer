# 🌌 [[Galaxy Visualizer]]

A high-performance 3D visualization platform that renders markdown notes as celestial bodies, orbital rings, and glowing cosmic splines.

## Integrations
- Visualizes any vault adhering to [[Open Knowledge Format (OKF v0.2)]].
- Illustrated in demo project [[Project Nebula]].
